# CSC4120 W10  Dynamic Programming

# I. Fibonacci & Shortest Path DP

## DP Basics

DP 的两个基本思想：

1. **Recursion**：把问题拆成子问题，并通过子问题的解得到原问题的解。
2. **Tabulation** / Memoization：每个子问题只计算一次，把结果存起来供以后使用；需要子问题解时查表，若无记录立即计算。

</br>

### Fibonacci Memorization

F<sub>1</sub> = F<sub>2</sub> = 1，F<sub>n</sub> = F<sub>n-1</sub> + F<sub>n-2</sub>

```python
def fib(n):
    if n <= 2:
        return 1
    return fib(n - 1) + fib(n - 2)
```

计算斐波那契 T(n) = T(n-1) + T(n-2) + O(1) = 𝛩(2<sup>n</sup>)

#### Memorized DP

避免指数级时间：计算出 F<sub>k</sub> 后保存结果——

```python
memo = {}
def fib(n):
    if n in memo: return memo[n]
    if n <= 2: result = 1
    else: result = fib(n - 1) + fib(n - 2)
    memo[n] = result
    return result
```

因为只有 F<sub>1</sub>, F<sub>2</sub>, ... F<sub>n</sub> 这 n 个不同的子问题，每个子问题第一次访问时真正计算；**虽然计算仍然无序，但之后访问时直接查表**，花费 O(1)。因此 **T(n) = 𝛩(n)**，额外**空间开销 S(n) = 𝛩(n)** (Memorization table + Recursion stack)

⚠️ 核心：子问题算且只算一次

</br>

### Bottom-up (non-recursive) DP 

我们也可以完全不使用递归，而是按顺序计算：F<sub>1</sub> → F<sub>2</sub> → ... → F<sub>n</sub>

```python
def fib(n):
    dp = [0] * (n + 1)  # 初始化长n+1的全0数组
    dp[1] = dp[2] = 1
    for k in range(3, n + 1):
        dp[k] = dp[k - 1] + dp[k - 2]
    return dp[n]
# 甚至只存每项的两个前序——
def fib(n):
    if n <= 2: return 1
    a, b = 1, 1
    for _ in range(3, n + 1):
        a, b = b, a + b
    return b
```

**T(n) = 𝛩(n)，S(n) = 𝛩(n) (⚠️ 只存两项时 𝛩(1))**，实际运行因为没有递归更快，但计算次数和 Memorized DP 相同。

Bottom-up 的计算顺序必须遵守 Dependency Ordering，即子问题 **Dependency Graph** 需要拓扑排序——⚠️ 必须是 DAG (**No circular dependency** 无环)。算法先填充没有依赖的表项，然后循环按拓扑顺序处理 (其依赖已知) 的表项。

- dependency graph (依赖图) 的边全部 **reverse** 就是 **causality graph (因果图) == tropological order**

这对高维依赖也适用，比如 2D：(𝑖, 𝑗) depends on (𝑖−1, 𝑗) & (𝑖, 𝑗−1)：

![](https://img.nero-lithos.com/posts/%E6%88%AA%E5%B1%8F2026-11-14%2009.45.02.png)

⚠️ DP 适用的主要条件：

- 可以从子问题的解组合得到原问题的解。
- 子问题间不存在 **Circular Dependency**。
- 存在 Overlapping Subproblems (重叠子问题)。
- 不同子问题数量相对较少，最好是 Polynomial。

## Shortest Path DP

设某有向图从 s  到 v 的最短距离为 δ(v)，直接想到 [**Bellman Equation**](https://blog.nero-lithos.com/posts/4120.6/#optimal-substructure--bellman-equation): δ(v) = min\{δ(u) + w(u, v)} 很合理，问题是如果图中有环 (non-DAG, u→t→u) 就有循环依赖，无法直接 DP 计算。

> 如果状态间存在循环依赖，试引入一个额外约束 k，切分子问题，把循环依赖转化为不同轮之间的依赖。

定义 δ<sub>k</sub>(s, v) 表示 s⇝v **最多**使用 k 条边的最短距离，这样循环依赖就从 δ(t) ↔ δ(u) 变为 δ<sub>k</sub>(t) → δ<sub>k-1</sub>(u) & δ<sub>k</sub>(u) → δ<sub>k-1</sub>(t) ——所有依赖都指向上一层 k-1，不再成环。

我们希望求 δ<sub>k</sub>(s, v)，初始化 δ<sub>0</sub>(s, s)=0，最优路径有两种可能：

- 不使用第 k 条边，距离为 δ<sub>k-1</sub>(s, v) 
- 使用最后一条边 (u,v)，那么到 u 的路径最多使用 k-1 条边，距离为 δ<sub>k-1</sub>(s, u) + w(u, v)

我们枚举所有可能的前驱 \(u\)，选最小值。因此 **Bellman-Ford DP** 完整递推式为：

> **δ<sub>k</sub>(s, v) = min\{δ<sub>k-1</sub>(s, v), min<sub>(u, v)∈E</sub> \[δ<sub>k-1</sub>(s, u) + w(u, v)]}**
>
> 1、**保留上一轮旧值继续比较**；2、**只能使用上轮距离结果**，不能使用本轮刚更新的值。
>
> (**课件使用了 δ<sub>k</sub>(s, v) = min<sub>(u, v)∈E</sub> \[δ<sub>k-1</sub>(s, u) + w(u, v)] 实际是不严谨的**)

⚠️ **只需要计算到 k =|V|− 1**，因为 δ<sub>|V|−1</sub>(s, v) = δ(s, v) ——在不存在负权环的情况下，如果一个最短路径重复访问某个节点，就包含一个 Cycle。这个 Cycle 的总权重不能为负，否则与无负权环的假设矛盾。删除这个 Cycle 不会增加路径长度，所以总存在一条最短的 Simple Path，最多经过 |V|− 1 条边 (逻辑类似 [Bellman-Ford](https://blog.nero-lithos.com/posts/4120.6/#bellman-ford-algorithm))

时间复杂度：对每个状态枚举所有前驱，子问题个数 x time/sub-problem = (|V|x|V|)x|V|

实际上，对于固定的 k，把所有节点的前驱边加起来，每条边只需要检查一次，因此每轮实际：O(|V|+|E|)，总共 O(|V|(|V|+|E|)) = **O(|V||E|)** (连通图)

</br>

### Example

![](https://img.nero-lithos.com/posts/%E6%88%AA%E5%B1%8F2026-11-14%2010.27.52.png)

Initialize δ<sub>0</sub>(s) = 0, δ<sub>0</sub>(t) = δ<sub>0</sub>(u) = δ<sub>0</sub>(v) = ∞;

Round 1: δ<sub>1</sub>(u) = min(δ<sub>0</sub>(u); 0+1, ∞+4) = 1, δ<sub>1</sub>(v) = min(δ<sub>0</sub>(v); 0+3, ∞+1) = 3, δ<sub>1</sub>(t) = (δ<sub>0</sub>(t); ∞+3, ∞+1) = ∞

Round 2: δ<sub>2</sub>(u) = min(1; 0+1, 3+4) = 1, δ<sub>2</sub>(v) = min(3; 0+3, 1+1) = 2, δ<sub>2</sub>(t) = min(∞; 1+3, 3+1) = 4

Round 3: δ<sub>3</sub>(u) = (1; 0+1, 2+4) = 1, δ<sub>3</sub>(v) = (2; 0+3, 1+1) = 2, **δ<sub>3</sub>(t) = min(4; 1+3, 2+1) = 3**

</br>

### 如何设计 DP Recurrence

⚠️ **Guess the last decision** (猜测最后一步)：以最短路径为例，我们不知道最后一条边是哪条，所以枚举所有可能的 u；**然后对每个候选 δ<sub>k-1</sub>(s, u) + w(u, v) 取 min** 

关键：(Polynomial) \# sub-problem = a; (polynomial) \# possible guess/sub-problem = b; Complexity = axb

**反之不成立**！Longest Simple Path 不可拆作“DP\[s, t]=max\{DP\[s, v] + DP\[v, t]}”，因为两段分别是各自子问题的最优解路径可能重复使用某些节点 (Not independent)：路径不一定简单

> Optimal Substructure 不仅要求子问题有最优解，还要求这些**子问题的解能够合法地组合**：**sub-problems can be solved independently**

## All-Pairs Shortest Paths

我们以往讨论的是 Single-Source Shortest Paths (SSSP)：给定源点 s 求距

All-Pairs Shortest Paths (APSP) 求所有两个节点之间的最短距离 δ(i, j)，假设无负权环，输出是一个 nxn 矩阵

### 方法一：限制边数

类似的，定义 d<sub>ij</sub><sup>(m)</sup> 表示 i⇝j 使用最多 m 条边的最短距离，初始化 d<sub>i=j</sub> = 0, d<sub>i≠j</sub> = ∞

递推 d<sub>ij</sub><sup>(m)</sup> = min\{d<sub>ik</sub><sup>(m-1)</sup> + a<sub>kj</sub>} 其中 a<sub>kj</sub> 表示从 k 到 j 的直接边权，没有边时为 ∞，且 a<sub>jj</sub> = 0

- 猜测最后一条边是 k → j，**O(|V|<sup>2</sup>|E|)** ～ O(n<sup>4</sup>)

</br>

### 方法二：限制 Intermediate Vertices

它不限制边数，而是限制路径中允许使用哪些中间节点。称为 **Floyd-Warshall** 算法 (O(|V|<sup>3</sup>))

定义 d<sub>ij</sub><sup>(m)</sup> 表示 i⇝j 只能使用编号在 \{1, ... m} 中的节点的最短距离

- 情况 A：不经过节点 m：d<sub>ij</sub><sup>(m)</sup> = d<sub>ij</sub><sup>(m-1)</sup>
- 情况 B：经过节点 m：d<sub>ij</sub><sup>(m)</sup> = d<sub>im</sub><sup>(m-1)</sup> + d<sub>mj</sub><sup>(m-1)</sup>

> Floyd-Warshall：**d<sub>ij</sub><sup>(m)</sup> = min\{d<sub>ij</sub><sup>(m-1)</sup>, d<sub>im</sub><sup>(m-1)</sup> + d<sub>mj</sub><sup>(m-1)</sup>}**

```python
def floyd_warshall(dist):
    n = len(dist)
    for m in range(n):
        for i in range(n):
            for j in range(n):
                dist[i][j] = min(
                    dist[i][j],
                    dist[i][m] + dist[m][j]
                )
    return dist
```

**不能随意交换三层循环顺序**。如果把 `m` 放到最内层，通常就不再遵循这个 DP 的依赖顺序。
