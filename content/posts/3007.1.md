# CSC3007 Week1

## 引入

> “Nothing at all takes place in the universe in which some rule of maximum or minimum does not appear.” —— Euler

MAT 3007 是一门指导你从合法决策集中找出使某指标最优（最大或最小）的决策的课程。优化的核心词是：**Decision(决策-变量或多变量组成的向量 x) + Objective(指标-优化目标 f = Objective Function) + Constraints(限制-现实或逻辑约束集 Ω)**

最简通式：min<sub>x</sub> f(x)  (subject to x ∈ Ω)

严格通式：min<sub>x∈R</sub> f(x)  (s.t. g<sub>i</sub>(x) ≤ 0, i = 1, ..., m；h<sub>j</sub>(x) = 0, j = 1, ..., p**)，有时也可能从离散集取值，比如 Z<sup>n</sup>

**转换标准形式**：1、max 加负号改成 min；2、多项不等式 g(x) ≥ y 改成 g(x) - s<sub>i</sub> = y，反之亦然；3、s<sub>i</sub> ≥ 0。

### 术语

- R<sup>n</sup> 表示 n 维实数域，在其中取一段连续值会组成一维线段/二维圆域/三维球域…

- Feasible point/solution：某一符合所有约束的决策 **x∈Ω := {x ∈ Rn : g(x) ≤ 0, h(x) = 0}**

- Feasible region：即 **Ω**，所有可行解组成的集合

- Optimal **Solution**：所有得到最优指标的可行解 **x<sup>\*</sup>**，实际问题解个数可能为任意自然数。

- Optimal **Value**：最优解对应的指标值 **f(x<sup>\*</sup>)**，有时记作 f<sup>\*</sup>

- 如果 Ω = R<sup>n</sup> 或 m = p = 0 就称问题为“无约束”(unconstrained)，反之就是“有约束”。
- Linear/Nonlinear：**指标是否为 n 元一次多项式**
- Continuous/Discrete：决策 x 取值的集是否连续
- Ω 空称为 infeasible。min 问题中 Optimal **Value **为 +∞ 称为 infeasible，−∞ 称为 unbounded；max 相反。

### 例子

在固定周长 C 的最大矩形问题中，决策是长和宽组成的 $x=\begin{bmatrix}l\\w\end{bmatrix}$；指标是 max(A = l·w)；约束是周长固定和长宽非负——$${\begin{aligned}\max_{l,w}&lw\ \ \ \ \text{s.t.}\ 2l+2w\le80;\ l,w\ge0\end{aligned}}$$

这是一个非线性优化（Constrained-Nonlinear-Continuous Optimization）

相比 MAT1001 Calculus，更关心问题的建模而非只求结果

### Minimizer/Maximizer

邻域的定义：**open ball** $B_\epsilon(y)=\{x\in\mathbb R^n:\|x-y\|<\epsilon\}$ 即以 y 为中心、半径为 ε 的小邻域。x<sup>\*</sup>满足以下条件时称为：

- 局部极小值点 (local minimizer)：存在 ε>0 使 open ball 中对应的可行值 f<sup>\*</sup> ≤ 邻域中所有其他 f
- 严格局部极小值点 (strict local minimizer)：局部极小值且 x ∈ (Ω ∩ B∈(x<sup>\*</sup>))\{x<sup>\*</sup>}（谷值唯一而非连续值）

- 全局极小值点 (global minimizer)：属于Ω 且对应的可行值 f<sup>\*</sup> ≤ 所有其他 f（严格全局极小值点类似），全局极小值点等价于 Optimal **Solution**。

⚠️ 不要滥用求导：f'(x) 只说明 x ∈ Stationary Point。f''>0 为 LMin，f''<0 为 LMax

### 最优解的四种情况

| **情况**                | x                                                            | optimal value                                            |
| ----------------------- | ------------------------------------------------------------ | -------------------------------------------------------- |
| Infeasible (min)        | Ω = ∅                                                        | 约定 f<sup>\*</sup>=+∞                                   |
| Unbounded below         | feasible x 存在                                              | f<sup>\*</sup>→-∞                                        |
| Finite but unattainable | feasible x 存在，不存在 feasible x<sup>\*</sup>，如超出约束/边界缺失或x→±∞ | f<sup>\*</sup> ∈ R                                       |
| Finite and attainable   | 存在 feasible x<sup>\*</sup>                                 | f<sup>\* </sup>∈ R，且f(x<sup>\*</sup>) = f<sup>\*</sup> |
