# CSC3007 Week1  Basics

## 引入

> “Nothing at all takes place in the universe in which some rule of maximum or minimum does not appear.” —— Euler

MAT 3007 是一门指导你从合法决策集中找出使某指标最优（最大或最小）的决策的课程。优化的核心词是：**Decision(决策-变量或多变量组成的向量 x) + Objective(指标-优化目标 f = Objective Function) + Constraints(限制-现实或逻辑约束集 Ω)**

最简通式：min<sub>x</sub> f(x)  (subject to x ∈ Ω)

严格通式：$$\begin{aligned}\min_{x\in\mathbb R^n}\quad &f(x)\\ \text{s.t.}\quad &g_i(x)\le0\\ &h_j(x)=0 \end{aligned}$$ 有时也可能从离散集取值，比如 Z<sup>n</sup>

**转换标准形式**：1、max 加负号改成 min；2、多项不等式 g(x) ≥ y 改成 g(x) - s<sub>i</sub> = y，反之亦然；3、s<sub>i</sub> ≥ 0；4、没有符号限制的变量 x<sub>i</sub> 必须写作 **a-b, s.t. a, b ≥ 0** 形式。

</br>

### 术语

- R<sup>n</sup> 表示 n 维实数域，在其中取一段连续值会组成一维线段/二维圆域/三维球域…
- Feasible point/solution：某一符合所有约束的决策 **x∈Ω := {x ∈ Rn : g(x) ≤ 0, h(x) = 0}**
- Feasible region：即 **Ω**，所有可行解组成的集合
- Optimal **Solution**：所有得到最优指标的可行解 **x<sup>\*</sup>**，实际问题解个数可能为任意自然数。
- Optimal **Value**：最优解对应的指标值 **f(x<sup>\*</sup>)**，有时记作 f<sup>\*</sup>
- 如果 Ω = R<sup>n</sup> 或 m = p = 0 就称问题为“无约束”(unconstrained)，反之就是“有约束”。
- 分类：Linear (LP)/Nonlinear (NLP)：**指标是否为 n 元一次多项式，LP 是最基础的**；Continuous/Discrete aka. Integer (IP)：决策 x 取值的集是否连续。每一对在特定情况下可以互相等价转换。**一般优化问题默认为连续的**。
- Ω 空称为 infeasible。min 问题中 Optimal **Value**为 +∞ 称为 infeasible，−∞ 称为 unbounded；max 相反。
- **inf 代表上界，sup 代表下界**；inf ∅ = +∞, sup ∅ = −∞

</br>

### Quick Example

在固定周长 C 的最大矩形问题中，决策是长和宽组成的 x = $\begin{bmatrix} l \\ w \end{bmatrix}$；指标是 max(A = l·w)；约束是周长固定和长宽非负——$${\begin{aligned}\max_{l,w}&lw\ \ \ \ \text{s.t.}\ 2l+2w\le80;\ l,w\ge0\end{aligned}}$$

这是一个非线性优化 (NLP)，具体来说是 Constrained-Nonlinear-Continuous Optimization

相比 MAT1001 Calculus，更关心问题的建模而非只求结果

</br>

### Minimizer/Maximizer

邻域的定义：**open ball** $B_\epsilon(y)=\{x\in\mathbb R^n:\|x-y\|<\epsilon\}$ 即以 y 为中心、半径为 ε 的小邻域。x<sup>\*</sup>满足以下条件时称为：

- 局部极小值点 (local minimizer)：存在 ε>0 使 open ball 中对应的可行值 f<sup>\*</sup> ≤ 邻域中所有其他 f
- 严格局部极小值点 (strict local minimizer)：局部极小值且 x ∈ (Ω ∩ B∈(x<sup>\*</sup>))\{x<sup>\*</sup>}（谷值唯一而非连续值）

- 全局极小值点 (global minimizer)：属于Ω 且对应的可行值 f<sup>\*</sup> ≤ 所有其他 f（严格全局极小值点类似），全局极小值点等价于 Optimal **Solution**。

⚠️ 不要滥用求导：f'(x) 只说明 x ∈ Stationary Point。f''>0 为 LMin，f''<0 为 LMax

</br>

### 最优解的四种情况

| **情况**                | x                                                            | optimal value                                            |
| ----------------------- | ------------------------------------------------------------ | -------------------------------------------------------- |
| Infeasible (min)        | Ω = ∅                                                        | 约定 f<sup>\*</sup>=+∞                                   |
| Unbounded below         | feasible x 存在                                              | f<sup>\*</sup>→-∞                                        |
| Finite but unattainable | feasible x 存在，不存在 feasible x<sup>\*</sup>，如超出约束/边界缺失或x→±∞ | f<sup>\*</sup> ∈ R                                       |
| Finite and attainable   | 存在 feasible x<sup>\*</sup>                                 | f<sup>\* </sup>∈ R，且f(x<sup>\*</sup>) = f<sup>\*</sup> |

inf A = −∞ if A is unbounded below

supA = +∞ if A is unbounded above（最大值问题）

## 建模

### 生产问题

公司生产两种合金，要决定各生产多少：

| \         | Steel | Iron | Copper | Profit |
| --------- | ----- | ---- | ------ | ------ |
| Alloy 1   | 1     | 0    | 1      | 1      |
| Alloy 2   | 0     | 2    | 1      | 2      |
| Available | 100   | 200  | 150    |        |

**Coefficients of LP**：0, 1, 100, 200, 150……

Decision Var.：x = [x<sub>1</sub>, x<sub>2</sub>]<sup>⊤</sup>（x<sub>1</sub>, x<sub>2</sub> 为 Alloy1/2 的生成量）

Objective Func.：Profit f(x) = x<sub>1</sub> + 2x<sub>2</sub>

Constraint：x<sub>1</sub> ≤ 100，x<sub>2</sub> ≤ 100，x<sub>1</sub> + x<sub>2</sub> ≤ 150，x<sub>1</sub>, x<sub>2</sub> ≥ 0

$$\boxed{ \begin{aligned} \max_{x_1,x_2}\quad &x_1+2x_2\ \text{s.t.}\quad &x_1\le100\ &2x_2\le200\ &x_1+x_2\le150\ &x_1,x_2\ge0 \end{aligned}}$$

</br>

### Shortest Path

*对于一个有向图 (左下)：G=(V,E)，每条边 (i, j) ∈ E 都有长度 w<sub>ij</sub> ≥ 0。从 S 到 T 走哪条路，总长度最短*？

![](https://i.postimg.cc/3xLBJVz1/tu-xiang.png)

建模时不能直接表示复杂对象，而是把复杂决策拆成很多简单变量。比如“走某条路”在数学上过于模糊，但如果对于每条 (i, j) ∈ E 定义：x<sub>ij</sub> ∈ {0, 1}（不使用/使用该边）于是“一条路径”就被编码成了一大堆 0/1，这里的决策变量就被转化为一个 11 维向量。

目标函数就是：$$\min_x \sum_{(i,j)\in E}w_{ij}x_{ij}$$（典型的 **0/1建模**）

约束：路径不能乱选，一定要“连续”且出现 S 和 T 恰好一次。换句话说，S 只出，T 只进，其余节点进出次数相等——

![](https://i.postimg.cc/LXNYDrf7/jie-ping2026-09-09-17-14-31.png)

线性目标函数，flow constraints 也是线性，但变量是离散的，所以这是这是整数 (离散) 线性优化 Integer Linear Optimization。

</br>

*另一个 0/1建模问题 (右上) 对一个 G，选最少的节点，使每条边至少有一个端点被选中*。

决策变量：x<sub>i</sub> ∈ {0, 1}（不使用/使用该边）

目标函数：$$\min\sum_{i\in V}x_i$$

约束：对于任意边  (i, j) ∈ E 必须选一个端点，即 **x<sub>i</sub> + x<sub>j</sub> ≥ 1**

显然这也是 Integer Linear Optimization。

# CSC3007 Week2  Linear Algebra

## Matrix version of LP

Matrix Notion: Standard form of LP ——

<div class="math-display">
$$
\boxed{
\begin{aligned}
\min\quad &c^Tx\\
\text{s.t.}\quad &Ax=b,\\
&x\ge0.
\end{aligned}}
$$
</div>



- 无常数线性多项式的向量的**内积 (点积)**表示：c<sup>T</sup>x = \[c<sub>1</sub>, ... c<sub>n</sub>] \[x<sub>1</sub>, ... x<sub>n</sub>]<sup>T</sup> = c<sub>1</sub>x<sub>1</sub> + ... + c<sub>n</sub>x<sub>n</sub>

- 矩阵 x 列向量 = 矩阵的每一行分别和向量做点积，结果是列向量：$(Ab)_i=\sum_{k=1}^n a_{ik}b_k$

- Ax = b 中，原本一条限制转为 A 的一行；一个 decision variable 就是 A 的一列——

  比如 x<sub>1</sub> ≤ 42; 2x<sub>2</sub> ≤ 400; x<sub>1</sub> + x<sub>2</sub> ≤ 150 

<div class="math-disply">
$$
A=
\begin{bmatrix}
1&0\\
0&2\\
1&1
\end{bmatrix},
\qquad
x=
\begin{bmatrix}
x_1\\x_2
\end{bmatrix},
\qquad
b=
\begin{bmatrix}
100\\200\\150
\end{bmatrix}.
$$
</div>



- A ∈ R<sup>mxn</sup> 说明 A 矩阵 m 行 n 列

- b = Ax ∈ R<sup>m</sup> 代表限制 (变量上限)

  相当于有 n 个变量；优化目标是它们的线性加权 (c<sup>T</sup>) 和；有 m 条线性方程限制它们；变量还必须非负。

## Linear Algebra Basics

**Transpose** (转置)：**把矩阵沿主对角线翻一下**，也就是“行变列、列变行”—— (A<sup>T</sup>)<sub>ij</sub> = A<sub>ji</sub>

- (AB)<sup>T</sup> = B<sup>T</sup>A<sup>T</sup>；(A+B)<sup>T</sup> = A<sup>T</sup> + B<sup>T</sup>
- **Symmetric Matrix** (对称矩阵)：转置之后还是自己，即沿主对角线两边镜像对称

**Inner Product** (内积/点积)：两个同维向量对应位置相乘再相加

- x<sup>T</sup>y = x<sub>1</sub>y<sub>1</sub> + x<sub>2</sub>y<sub>2</sub> + … + x<sub>n</sub>y<sub>n</sub>，结果是一个**数 (scalar)**，不是 vector
- x<sup>T</sup>y = 0 ⇒ x 与 y **orthogonal (正交/垂直)**

**Norm** (范数 / 向量长度)：衡量 vector 的“大小/长度”，写成 ||x||

- **L<sub>2</sub> norm**：||x||<sub>2</sub> = √(x<sub>1</sub><sup>2</sup>+ … + x<sub>n</sub><sup>2</sup>)，即欧氏距离。||x||<sub>2</sub><sup>2</sup> = x<sup>T</sup>x
- **L<sub>1</sub> norm**：||x||₁ = |x₁| + … + |xₙ|
- **L∞ norm**：||x||∞ = max |xᵢ|

**Matrix Multiplication**：A 是 m×n，B 是 n×p，才能计算 AB：**(m×n)(n×p) → (m×p)**

- (AB)<sub>ij</sub> = A 的**第 i 行** · B 的**第 j 列**——通常 **AB ≠ BA**，所以矩阵乘法不能随便换顺序

 **Linear Independence** (线性无关)：一组向量中，**没有任何一个能由其他向量线性组合出来**

**Span** (张成空间)：一组向量通过“随便乘系数再相加” (**线性组合 LC**) 能够制造出来的**所有向量的集合**

- 比如 span\{\[1, 2]<sup>T</sup>, \[0, 1]<sup>T</sup>} = R<sup>2</sup>，**n 维空间 R<sup>n</sup> 至少需要 n 个线性无关的向量张成**——

- 这样的向量集合称为 **Basis** (基)：描述整个空间所需要的一套“不重复的基本方向”

**Rank** (秩)：矩阵中有多少个**独立的方向**；等价于 **线性独立列/行** 的最大数量

-  对于 A<sup>m×n</sup>，rank(A) ≤ min(m,n)
- **rank(A) = rank(A<sup>T</sup>)**；rank(AB) ≤ min(rank(A), rank(B))
- **Full rank** (满秩)：rank 已经达到可能的最大值 (m 和 n 的较大值)

**Identity Matrix** (单位矩阵)：矩阵的“1”，写作 **I**；主对角线全是 1，其他位置都是 0

- AI = IA = A

**Inverse**（逆矩阵）：矩阵版本的“倒数”；AA<sup>−1</sup> = A<sup>−1</sup>A = I。所以 A<sup>−1</sup> 可理解成**撤销 A 做的线性变换**

- **A 是 n×n square matrix + full rank 才可逆**

- (A<sup>−1</sup>)<sup>−1</sup> = A；**(AB)<sup>−1</sup> = B<sup>−1</sup>A<sup>−1</sup>**

- **Orthogonal Matrix** (正交矩阵)：各列都是互相垂直、长度为 1 的 vectors

  A<sup>T</sup>A = AA<sup>T</sup> = I，所以 **A<sup>−1</sup> = A<sup>T</sup>**

**PSD/SD** (半正定/正定矩阵)：PSD 对任意 x 有 x<sup>T</sup>Ax ≥ 0；PD 对任意 非 0 x 有 x<sup>T</sup>Ax > 0

- A<sup>T</sup>A 和 AA<sup>T</sup> 一定是 PSD

⚠️ 行列式 **det(A) ≠ 0 ⇔ A 可逆 ⇔ 如果 A 为方阵，满秩且rank(A) = n ⇔ A 的 n 个 columns 和 rows 线性无关 ⇔ Ax = 0 只有零解 x = 0 ⇔ 对任意 b，Ax = b 有唯一解 ⇔ A 的 columns 构成 Rⁿ 的一个 basis**

- **det(AB) = det(A)det(B)**、**det(AT) = det(A)**、**det(A−1) = 1/det(A)**、det(I) = 1

## Machine Learning & Vector Machine

Support Vector Machine 支持向量机：一个机器学习问题怎么转为优化问题

ML 中的 sample 即将某对象的各种 numerical features 打包成向量 x

一个 training sample (Supervised Learning) 就是 (x<sub>i</sub>, y<sub>i</sub>) 其中 y 代表这个实例的 (分类) 答案

### hard-margin SVM

假设现在只有两个 features，对象可以画成平面上的点，现在想找一条直线 (**linear classifier**) 把两个类型分开，两类答案记作 y = 1 和 y = -1

直线 l(x) = ω<sup>T</sup>x + b = 0 ⇔ ω<sub>1</sub>x<sub>1</sub> + ω<sub>2</sub>x<sub>2</sub> + b = 0

在 SVM optimization 里，ω 和 b 是决策变量，给定一些 (x<sub>i</sub>, y<sub>i</sub>) 作为训练样本

> **Find ω, b      s.t.  y<sub>i</sub> (ω<sup>T</sup>x<sub>i</sub> + b) ≥ 1**，(feasibility problem：min ω, b 优化问题的特殊情况)

SVM 想让分类尽量分宽 (边界冗余最大)，规定人为边界 ω<sup>T</sup>x + b = -1 (type1 附近) 和 ω<sup>T</sup>x + b = 1 (type-1 附件)，中间的最优 classifier 就是 **ω<sup>T</sup>x + b = 0**，它距离两个边界有相等的 **margin = 2/||ω||**，显然要 maximize margin，即——

> **min<sub>ω, b</sub> ||ω||<sup>2</sup>/2      s.t.  y<sub>i</sub> (ω<sup>T</sup>x<sub>i</sub> + b) ≥ 1**

</br>

### soft-margin SVM

Hard-margin SVM 有一个很强的要求：**每个点都必须被正确分开，而且在 margin 外面**。

如果任意直线都不能完美分开就属于 **non-linearly separable / non-separable data**

只能允许犯错，但犯错要付代价 (**Hinge loss**)

**Hinge loss = max\{0, 1 − y<sub>i</sub>(wᵀx<sub>i</sub>+b)}** 处罚所有不满足 y<sub>i</sub> (ω<sup>T</sup>x<sub>i</sub> + b) ≥ 1，即进入 margin 区域的点——比如落在 l(x) 上罚 1。可理解为这个 sample 离“hard-margin 合格线”还差多少——

> **min<sub>ω, b</sub> ||ω||<sup>2</sup>/2 + Σ<sub>i</sub> max{0, 1 − y<sub>i</sub> (wᵀx<sub>i</sub> + b)}**
>
> **s.t.  y<sub>i</sub> (ω<sup>T</sup>x<sub>i</sub> + b) ≥ 1**

这是一个 unconstrained + nonlinear + continuous Optimization

</br>

### Linear-fication of SVMs

min Σ<sub>i</sub>t<sub>i</sub>    s.t. t<sub>i</sub> = max<sub>i</sub>\{a, b} 可以宽松写作 **t<sub>i</sub> ≥ max<sub>i</sub>\{a, b}**，进一步写成 **s.t.  t<sub>i</sub> ≥ a AND  t<sub>i</sub> ≥ b**。

> 有时候不需要用 constraint 强迫相等；objective 自己会把 inequality 推到边界。

min abs(f) 可以宽松写作 f ≤ t, -f ≤ t    s.t. t ≥ 0

## Linear-fication

LP：**Objective function 和所有 constraints 都必须对决策变量是线性的**。

- 即，它们可以写作线性多项式等式或不等式 (ω<sup>T</sup>x ≥ b 或 ω<sup>T</sup>x = b)

类似于 SVM 的例子，我们通常想把 NLP 转为更简单的 LP：

<div class="math-display">
$$
\boxed{
\begin{aligned}
\min\quad &c^Tx\\
\text{s.t.}\quad &Ax=b,\\
&x\ge0.
\end{aligned}}
$$
</div>

要求 A<sup>mxn</sup> full row rank (行独立) 且 m < n (限制方程数量少于决策变量数的**宽阵**)，故 rank(A) = m

- 因为如果多元线性方程组数量 ≥ 变量数要么直接解出答案要么解不出 (不属于优化问题)

⚠️ **转换为标准 LP**：

1、max 加负号改成 min；

2、多项不等式 aᵀx ≤ b 改成 g(x) + s<sub>i</sub> = b (s<sub>i</sub> ≥ 0)，反之亦然；

3、x<sub>i</sub> ≤ 0 改成 x<sub>i</sub> = -y<sub>i</sub>, y<sub>i</sub> ≥ 0

4、没有符号限制的变量 (free var.) x<sub>i</sub> 必须写作 **a-b, s.t. a, b ≥ 0** 形式。

</br>

### Maximin & Minimax

空管想要最大化 n 架客机的最短降落时间间隔：maximize min\{t<sub>j+1</sub>−t<sub>j</sub>}

Linear-fication：Def ∆ = min<sub>j=1,...,n-1</sub> \{t<sub>j+1</sub>−t<sub>j</sub>}，宽松 ∆ ≤ t<sub>j+1</sub>−t<sub>j</sub>，然后 **max ∆** 即可

> **和 SVM 中 max 的处理方式相对应**：

Minimax (soft-bound SVM)：**min maxᵢ fᵢ(x)** ——

> **min t**
> s.t. **t ≥ fᵢ(x), ∀i**
>
> “t 在所有东西上面，然后往下压”

Maximin (ATC problem)：**max minᵢ fᵢ(x)** ——

> **max t**
> s.t. **t ≤ fᵢ(x), ∀i**
>
> “t 在所有东西下面，然后往上顶”

</br>

类似的，绝对值 |wᵀx+b| 相当于 **max\{wᵀx+b, -wᵀx-b}**

比如 min abs(f) 可以宽松写作 f ≤ t, -f ≤ t    s.t. t ≥ 0

>⚠️ 如果你希望 **t = f(x)** 但放宽到 t ≥ f(x)，那么必须有某种原因迫使 t **变小**，例如 min t。

</br>

### LFP (Linear Fractional Problem)

min (c<sup>T</sup>x+d)/(e<sup>T</sup>x+a)      s.t. Ax≤b, eᵀx+a > 0（显然不是 LP）

定义：**y = x/(e<sup>T</sup>x+a)**、**z = 1/(e<sup>T</sup>x+a)**

因为 y = zx，所以 (c<sup>T</sup>x + d)/(e<sup>T</sup>x + a) = z(c<sup>T</sup>x + d) = **c<sup>T</sup>y + dz**

Ax ≤ b ≡ zAx ≤ bz ≡ Ay - bz ≤ 0，因为 **z(e<sup>T</sup>x+a) = 1** 所以 **eᵀy+az=1**

> minimize　cᵀy+dz
>
> s.t.  Ay−bz≤0, eᵀy+az=1, z≥0

---
